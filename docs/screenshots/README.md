## 重新生成

截图是自动化采集的，数据来自本地 Mock：干净启动（清空 localStorage）→ 填写示例产品 → 生成 → 依次切换到各界面截图。若要重做，用 Mock 模式启动后按上表逐屏采集即可，注意：

- 采集前先清空 `localStorage`，否则可能带上上一次的资产与统计
- 视口宽度统一 1440px，高度按内容长度调整（上表已给出）
- 关闭滚动条渲染（headless 浏览器默认行为）以保证版面干净
- **建议选 3 种风格、共 6 篇**（每种 2 篇）。Mock 的每种风格只有 3 条模板，
  单一风格且篇数 > 3 时会循环复用，角度区会出现成对的重复行、多样性显示
  「重复风险 中」——那是 Mock 的已知限制，但放进截图容易被误读为产品缺陷
- 视口高度：`01` 1000 / `02` 1240 / `03` 1560 / `04` 1180 / `05` 1240 / `06` 1360

> 截图采集于 2026-09-27，对应卡片**三级分层**改版（L1 主层 / L2 摘要层 / L3 折叠分析抽屉）。
> `03-notecard.png` 同屏并列展示了展开态（左）与收起态（右）。

## 如何查看界面

**不需要模型凭据**，用 Mock 模式即可查看全部界面（不消耗 AI 额度）：

```bash
npm install
VITE_USE_MOCK_DATA=true npm run dev:web
```

打开 <http://localhost:5173>，页面底部状态栏会显示「Mock 模式（不消耗额度）」。

Mock 模式下的文案由本地确定性逻辑生成，会随输入变化，用于界面展示是合适的；但它**不是真实模型输出**，截图说明中不宜把 Mock 结果描述为"AI 生成效果"。
